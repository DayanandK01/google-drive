### 📂 Google Drive Project  

This repository contains the **Google Drive** project, which provides functionalities related to file storage, management, and sharing.  

## 🚀 Features  
- Secure file storage  
- Easy file sharing  
- Efficient organization and access  

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/DayanandK01/uber-clone.git
   cd uber-clone
   ```
2. **Install frontend dependencies**
   ```bash
   npm install
   ```
3. **Install backend dependencies**
   ```bash
   npm install
   ```
4. **Environmet variables**
   MONGO_URI
   JWT_SECRET_KEY
   
5. **Run the backend
   ```bash
   npm run server
   ```
6. **Run the Frontend**
   ```bash
   npm start
   ```
